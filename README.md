# Stigg Design System · visual reference

**Open it: https://stiggio.github.io/stigg-design-system/**

The whole Stigg design system on one page: colors, typography, logos, components and states,
product UI, marketing blocks, deck layouts, imagery, motion, and downloads (logos as SVG/PNG,
favicons, the Geist fallback font).

This public preview is set in **Geist**. The brand typeface, Söhne (Klim Type Foundry), is licensed
for internal use and isn't published here.

Using Claude at Stigg? The design system is already installed for you in claude.ai and Cowork; just
ask for anything visual. Engineers using Claude Code, Codex or Cursor: see the internal repo
`stiggio/marketing-public`.
